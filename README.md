# Solar Energy Monitor

A Java desktop application for monitoring and visualizing solar energy production, battery status, and grid usage with real-time statistics and historical data analysis.

## Features

- **Real-time Monitoring**
  - Current battery charge percentage
  - Battery charging/discharging status with time remaining estimation
  - Solar power generation (Watts)
  - Grid import/export status (Watts)
  - House energy consumption calculation

- **Data Visualization**
  - Time-series charts showing daily energy trends
  - Solar generation tracking
  - Grid export/import visualization
  - Interactive chart with zoom and pan capabilities

- **Cost Analysis**
  - Daily energy usage and cost breakdown
  - Monthly aggregated statistics
  - Export revenue calculation ($0.067/kWh)
  - Grid usage cost tracking ($0.19030/kWh)

- **Battery Management**
  - 11.8 kWh battery capacity monitoring
  - Real-time discharge time estimation
  - Charging/discharging power display

## Prerequisites

- **Java Development Kit (JDK)** 17 or higher
- **Apache Maven** 3.x
- **MySQL Database** 5.7 or higher

## Database Setup

1. Create a MySQL database named `solarpv`:
```sql
CREATE DATABASE solarpv;
```

2. Create the `solarusage` table:
```sql
USE solarpv;

CREATE TABLE solarusage (
    id INT AUTO_INCREMENT PRIMARY KEY,
    dateTime DATETIME NOT NULL,
    solarpower INT,
    gridPower INT,
    batteryPower INT,
    batteryCapacity INT,
    INDEX idx_datetime (dateTime)
);
```

3. Create the database user (or use your existing credentials):
```sql
CREATE USER 'solarpv'@'localhost' IDENTIFIED BY 'solarpvpw';
GRANT ALL PRIVILEGES ON solarpv.* TO 'solarpv'@'localhost';
FLUSH PRIVILEGES;
```

4. Configure database connection in `Monitor.java` (line 566) if needed:
```java
Connection con = DriverManager.getConnection(
    "jdbc:mysql://localhost:3306/solarpv", 
    "solarpv", 
    "solarpvpw"
);
```

## Usage

1. **Launch the application** - The main window displays current solar system status
2. **View real-time data** - The right panel shows current battery, solar, and grid statistics
3. **Analyze daily usage** - The bottom-left table shows daily energy breakdown and costs
4. **Review monthly costs** - The bottom-right table shows monthly aggregated data
5. **Refresh data** - Click the "Refresh" button to update all displays with latest data

## Data Flow

The application reads solar power data from the MySQL database at 10-second intervals, processing:
- **Solar Power** - Energy generated by solar panels (Watts)
- **Grid Power** - Energy exported (+) or imported (-) from grid (Watts)
- **Battery Power** - Energy charging (+) or discharging (-) from battery (Watts)
- **Battery Capacity** - Current battery charge level (percentage)

## Cost Calculations

- **Export Rate**: $0.067 per kWh
- **Import Rate**: $0.19030 per kWh

These rates are configurable in the `createDataset()` method (lines 317, 348).

## Customization

### Battery Capacity
To modify the battery capacity (default 11.8 kWh), edit line 394 in `Monitor.java`:
```java
double total_bat_kwh = 11.8 * 1000;  // Change to your battery capacity
```

### Electricity Rates
To update electricity rates, modify lines 317 and 348 in `Monitor.java`:
```java
dailyExport * 0.067      // Export rate
dailyGrid * 0.19030      // Import rate
```

## Troubleshooting

### Database Connection Issues
- Verify MySQL is running: `mysql -u solarpv -p`
- Check database credentials in `Monitor.java`
- Ensure MySQL connector JAR is included in classpath

### Chart Not Displaying
- Check that data exists in the `solarusage` table
- Verify date/time values are properly formatted
- Review console output for exceptions

### Application Won't Start
- Confirm Java 17+ is installed: `java -version`
- Verify all dependencies are available: `mvn dependency:tree`
- Check for port conflicts with MySQL (default: 3306)
